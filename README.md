# Project Name: 
              Dev Stack

# Description:
              Dev Stack is a web application that allows users to explore different technologies and build their own technology stack.

## Used Technologies:
              1. React
              2. Typescript
              3. JavaScript  
              4. Tailwind CSS
              5. React Icons
              6. React Toastify
              7. Vite
              8. Custom font- (Plus Jakarta Sans)

## 3 Features About My Project:
              1. Explore different technologies
              2. Add technologies to your stack
              3. Remove individual or all technologies

## React questions answer:
              1. JSX is a syntax where we can write HTML like code inside JavaScript. It is used in react because it makes react code easier to write and understand.

              2. Props are used to pass data from on component to another and State is used to store data that can change.

              3. `useState` is used to store and update data. I used it to store the selected technologies in the stack.

              4. `useEffect` is used to run code after a component loads. It can be used to load data from a JSON file.

              5. A unique `key` helps React identify each item in a list. It helps React update the list correctly.

              6. Conditional rendering means showing something based on a condition. I used it to show the empty stack message when there are no selected technologies.

              7. A parent sends data to a child using props. A child can send data back by calling a function passed through props.
